# SignatureLab — Generated Outputs Directory

This directory stores downloadable project deliverables generated by the studio:
1. `Linear_Algebra_Signature_Verification_Report.pdf`: Official academic project report formatted for submission.
2. `Linear_Algebra_Signature_Verification_Report.docx`: Editable Microsoft Word academic report.
3. `batch_verification_results.csv`: Exported empirical verification data with computed dot products, norms, distances, and decisions.

To re-generate deliverables at any time, run:
```powershell
python -m src.report_generator
```
or use the **📄 Project Documentation** module in the web application.
